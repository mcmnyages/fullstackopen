
# Welcome to Blog App

This is a modern blogging platform built with Next.js, featuring user authentication, blog post management, and a clean, intuitive interface.

---

## Features

- **Create and Manage Blogs** – Write, publish, and manage your thoughts.
- **User Profiles** – Explore personalized user pages.
- **Authentication** – Secure login and registration.
- **Comments** – Engage with blog posts and share your thoughts.

## Getting Started

To start exploring the platform:

1. Register for a new account.
2. Log in to access your dashboard.
3. Create a new blog post.
4. View all blogs and users.

---
